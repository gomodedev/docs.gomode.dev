# Go Mode documentation website

This repository owns docs.gomode.dev, built with VitePress and hosted as Cloudflare Workers static assets. Documentation covers the reusable Go Mode platform. caic owns coding-agent workflows; its UI and md documentation belong at docs.caic.xyz.

## Source of truth

Read `/home/user/src/gomode/README.md`, the relevant source, and upstream guides before updating pages. Design plans are not shipped behavior. Native external-browser login and progressive skill activation must not be described as implemented until source proves them.

Read current [Cloudflare documentation](https://developers.cloudflare.com/workers/static-assets/) before changing deployment configuration. Configure navigation in `.vitepress/config.ts` and presentation in `.vitepress/theme/`.

## Authoring and validation

Each guide page starts with one H1. Use H2 and H3 sections, language-tagged code blocks, and relative internal links without `.md`. Frontmatter belongs on the homepage. Check code examples against the actual upstream API.

Install hooks with `scripts/install-git-hooks.sh` before changes. Run `pnpm run fix`, `pnpm run verify`, `pnpm run build`, and `pnpm exec wrangler deploy --dry-run`. Verify desktop/mobile navigation, local search, keyboard interaction, screenshots, and 404 responses in a browser.

## Captures

Go Mode produces WebP captures in `e2e/screenshots/android`. Use `pnpm run screenshots --source ../gomode/e2e/screenshots/android` to import current captures. The hosted-service scenario is a generic demonstration frontend. Do not imply that it is caic’s task UI or that Halo settings prove a physical device connection.

Builds use committed captures without a sibling checkout or emulator. Do not hand-edit generated images. External Workers Builds and custom-domain setup is documented in README.md.
